# Prompt assets

Reusable prompt and instruction assets that accompany the concept — for example system
prompt skeletons, evaluation rubrics and review checklists.

Prompt assets are versioned artefacts: they change agent behaviour as much as code does,
so they follow the same review, release and evaluation gates. See
[Evaluation engineering](../../02-Enterprise-Capabilities/Data-Capabilities.md) and the
[AI platform](../../03-Architecture-Concept/AI-Platform.md).
